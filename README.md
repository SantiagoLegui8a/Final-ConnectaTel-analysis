# Final-ConnectaTel-analysis

1. El objetivo del proyecto

Este es un estudio estadístico de la empresa ConnectaTel y su objetivo principal es entender cómo los clientes usan los servicios móviles, detectar valores atípicos y segmentar usuarios para mejorar la oferta comercial. Por lo anterior, se pretendera analizar los grupos de consumo por categoria de producto y el rango  de edades que se ven involucradas en este estudio. 

2. Los datasets utilizados

Para este análisis se utilizaron los datasets plans.csv, users_latam.csv y usage.csv; para las cuales se habilitaron las librerías de pandas, seaborn y matplot.pyplot.

3. Las etapas del análisis realizadas

El proceso de análisis comprendio las siguientes etapas: 
-- Carga de bases 
-- Exploración de datos
-- Verificación del estado de la información disponible.
-- Corrección y limpieza de datos.  
-- Agrupación y análisis comportamental.
-- Visualización de distribuciones e identificación de outliers.
-- Segmentación de clientes
-- Insights y recomendaciones.
